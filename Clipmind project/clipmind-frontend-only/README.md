# ClipMind AI — Frontend (UI/UX only)

Module 1 document ke pages: Registration, Login, Dashboard, Upload, History.

## Run karne ke liye

```bash
npm install
npm run dev
```

Browser mein khulega: **http://127.0.0.1:5173**

Note: Ye sirf UI hai. Backend API (`http://127.0.0.1:8000`) chal raha hoga tabhi
Register/Login/Upload/History real data ke saath kaam karenge (dekho `src/api.js`).
